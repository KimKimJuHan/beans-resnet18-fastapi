# 응답시간 측정 요약 (중앙값, ms)

- 서버: http://127.0.0.1:8000
- 이미지 폴더: dataset/test
- 반복: 조건별 5회 (warmup 1회 제외)
- 비동기 상태조회 간격: 0.2초 (final_ms에 포함)

| 경로 | 캐시 | 횟수 | HTTP 응답 | 최종 결과 확인 | 모델 추론(inference_ms) |
|---|---|---:|---:|---:|---:|
| 동기 | MISS | 5 | 20.2 | 20.2 | 16.2 |
| 동기 | HIT | 5 | 1.5 | 1.5 | NULL |
| 비동기(HTTP=접수) | MISS | 5 | 12.3 | 221.7 | 19.0 |
| 비동기(HTTP=접수) | HIT | 5 | 11.4 | 220.6 | NULL |

- 예상과 다른 캐시 상태: 0건 (이미 보낸 이미지였거나 캐시가 꺼져 있으면 발생)
- HIT의 inference_ms=NULL은 모델 추론을 생략했다는 뜻이며 0ms가 아닙니다.
- 비동기 HTTP 시간은 '접수' 시간이고, 실제 결과는 '최종 결과 확인' 열입니다.
